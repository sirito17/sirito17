## 👋 About me

I'm a cybersecurity student at **Virginia Tech (Class of 2028)** and a member of **CyberVT** and the **Virginia Tech Corps of Cadets**. Most of my building happens at the intersection of **security engineering, automation, and AI agents** — lately, autonomous trading systems.

- 🛡️ I design for failure first: kill switches, circuit breakers, idempotent orders, audit logs, and external watchdogs
- 🧪 I don't trust a strategy until it survives realistic costs, out-of-sample data, and a power analysis
- 🤖 I pair-program daily with AI coding agents (Claude Code, Codex) and build the guardrails that keep them honest
- 📈 Trading started as a way to learn markets — it turned into a crash course in risk management and distributed systems

## 🧠 How I build

| Principle | What it looks like in practice |
| --- | --- |
| **Fail safe, not fail silent** | HALT kill switch, equity circuit breaker, and an external monitor that pages me when a scheduled run *doesn't* happen |
| **Least privilege** | Research tools have no broker code at all; order scripts are capability-gated; paper-only endpoints are enforced in code |
| **Prove it before you trust it** | Pre-registered train / validation / holdout splits, realistic trading costs, and statistical power checks |
| **Everything is auditable** | Append-only trade logs, run-log integrity checks in CI, and every config change voids prior authorization |
| **Honest reporting** | If a strategy has no edge, the code says so — one profile literally ships labeled `MECHANICS_ONLY_NO_EDGE` |
